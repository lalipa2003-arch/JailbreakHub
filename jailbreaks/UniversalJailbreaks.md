# 🗺️ Universal Jailbreaks

This is where, all the jailbreaks that don't fit for specific models (like Deepseek, Qwen, etc) live. Inside this folder, you will see a lot of `.txt` and `.md` files tracking different prompts. These prompts may or may not be patched, and, are not for specific models. 
If you find files with the name unverified, that means it has not been verified for any models, or have been tested.
